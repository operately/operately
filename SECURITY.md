# Security Policy

## Reporting a vulnerability

Report security issues privately through [GitHub's vulnerability reporting form](https://github.com/operately/operately/security/advisories/new). Do not use public issues, pull requests, or community channels.

Include the impact, affected version or commit, deployment details, steps to reproduce, and logs or screenshots with sensitive data removed. Keep details private and coordinate publication with the maintainers.

## Security updates

See [releases](https://github.com/operately/operately/releases) and [published security advisories](https://github.com/operately/operately/security/advisories).
