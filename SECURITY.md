# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Operately, please report it privately
through [GitHub's vulnerability reporting form](https://github.com/operately/operately/security/advisories/new).
You will need to sign in to GitHub to submit a report.

Please do not report vulnerabilities in public GitHub issues, pull requests, or
community channels.

Include the following details where possible:

- A description of the vulnerability and its potential impact.
- The affected Operately version or commit and relevant deployment details.
- Steps to reproduce the issue, including a minimal proof of concept if available.
- Relevant logs or screenshots, with credentials and personal data removed.

Use the private report to share follow-up information and coordinate disclosure
with the maintainers. Please keep vulnerability details private until a fix or
mitigation is available and disclosure has been coordinated.

## Security updates

Keep your installation up to date. See [Operately releases](https://github.com/operately/operately/releases)
for release notes and [published security advisories](https://github.com/operately/operately/security/advisories)
for disclosed vulnerabilities.
